# Convite Stella 15 Anos

Convite digital dos 15 anos da Stella: envelope que se abre na tela, céu com lanternas animadas e confirmação de presença pelo WhatsApp.

- `public/index.html`: o site inteiro, em um único arquivo.
- `firebase.json`: configuração do Firebase Hosting.

## Publicar

```
npm install -g firebase-tools
firebase login
firebase deploy --only hosting --project stella-15-anos
```
